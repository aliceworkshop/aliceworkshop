{%- comment -%} Weekly timetable built from _data/program.yml. On wide screens it is a grid with one column per day; on narrow screens it falls back to a list per day. Each day is split into 12 sub-columns so that 2, 3, 4 or 6 sessions can run side by side, and a day's `width` sets its relative column width. On phones, tapping a day header collapses that day (a hidden checkbox per day). Clicking a block opens its details in a popover.
